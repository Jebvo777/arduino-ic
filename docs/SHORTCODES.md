# Все шорткоды MIK Shop 1.3.0

В Elementor используйте виджет **«Шорткод»**. Для широких блоков задайте контейнеру ширину 100%. Не добавляйте второй аналогичный блок стандартного WooCommerce в ту же область.

## Хедер и футер

| Шорткод | Что выводит / где разместить |
|---|---|
| `[mik_logo]` | Новый синий логотип с названием «Купить микросхемы и транзисторы», рядом Electronic Component. Заменяет статический YourLogo в шаблоне хедера. |
| `[mik_catalog_button]` | Кнопка раскрывающегося каталога с иерархией и поиском категорий. |
| `[mik_search]` | AJAX-поиск с предварительными результатами и переходом к результатам на `/shop/`. |
| `[mik_account_icon]` | Иконка личного кабинета с миниокном. |
| `[mik_wishlist_icon]` | Иконка избранного с миниокном. |
| `[mik_cart_icon]` | Иконка корзины с миниокном. |
| `[mik_store_status]` | Телефон, рабочее время и статус магазина. |
| `[mik_header_categories]` | Горизонтальная строка главных категорий. Вставить вместо «Тут категории будут». |
| `[mik_mobile_menu]` | Иконка открытия полноэкранного мобильного меню со страницами и блоками магазина. |
| `[mik_footer]` | Полный футер: логотип, страницы, поиск по категориям и контакты. Фон `#242A33`, скругление 5 px. |

Пример короткой строки: `[mik_header_categories limit="5"]`.

Выбранные категории: `[mik_header_categories ids="101,102,103" limit="3"]`. Замените числа на ID категорий вашего сайта. Если `ids` не заданы, после преобразования используются восемь основных родителей.

## Главная и каталог

| Шорткод | Что выводит / где разместить |
|---|---|
| `[mik_slider]` | Главный баннер: редактируемые тексты/ссылки и попеременная смена двух присланных фотографий. |
| `[mik_category_cards]` | Восемь карточек основных категорий по последнему скриншоту: заголовок, дочерние ссылки, фото товара, «Подробнее». |
| `[mik_products_carousel]` | Карусель товаров с настройками из админки. |
| `[mik_catalog]` | Шаблон **Product Archive** в Elementor. На `/shop/` — родительские категории; в категории — товары и фильтры. |
| `[mik_product]` | Шаблон **Single Product** в Elementor: галерея, описание, характеристики, PDF, похожие товары и действия. |

Примеры карточек категорий:

```text
[mik_category_cards limit="8" children="3"]
[mik_category_cards ids="101,102,103" limit="3"]
[mik_category_cards parent="101" limit="12" children="0"]
```

Параметры новых категорийных шорткодов:

| Параметр | Значение |
|---|---|
| `limit` | Максимальное число выводимых разделов. Для новых блоков по умолчанию 8; в настройках 1–24, в самом шорткоде до 48. |
| `ids` | ID нужных категорий через запятую. Необязательный. |
| `parent` | ID родителя для вывода его непосредственных дочерних разделов. Необязательный. |
| `children` | В карточках: количество дочерних ссылок, 0–6. По умолчанию 3. |

Примеры товаров:

```text
[mik_products_carousel title="Новые поступления" source="new" limit="12" columns="4"]
[mik_products_carousel title="Рекомендуем" source="featured" limit="12"]
[mik_products_carousel source="all" category="mik-mosfet" limit="12"]
[mik_catalog per_page="24" view="grid"]
[mik_catalog category="101" per_page="24" view="list"]
[mik_product id="123"]
```

В примерах `category`, `id` и `parent` замените на значения вашего сайта. В шаблоне товара ID вручную не нужен — берётся открытый товар. Для предпросмотра шаблона Elementor выберите пример товара.

Итого 28 зарегистрированных шорткодов. Контент информационных страниц, тексты, цвета, контакты, слайды и настройки новых категорийных блоков меняются в MIK Shop. Адреса страниц задаются в настройках относительно действующей установки WordPress: `/wp6/` не нужно вручную дописывать к примеру шорткода.

## Порядок подключения новых категорий

1. Установить обновление.
2. **MIK Shop → Категории → Создать копию и преобразовать категории**.
3. Дождаться завершения серверного задания.
4. В хедер вставить `[mik_header_categories]`, в тело главной — `[mik_category_cards]`.
5. В шаблоне хедера заменить старую картинку YourLogo на `[mik_logo]`.

До преобразования новые блоки могут использовать текущие корневые категории. После преобразования автоматически выбираются восемь новых главных разделов, если вы не указали собственные ID.
