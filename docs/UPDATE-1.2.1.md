# MIK Shop 1.2.1

Число в поле размера означает максимальный размер одного ZIP. При вводе `800` все товары каталога распределяются на архивы не более 800 МБ каждый. Общая сумма архивов этим значением не ограничивается.

Ранее дополнительное ограничение 500 товаров закрывало пакет раньше, чем достигался размер файла. Общие изображения и PDF также завышали оценку: план считал их для каждого товара, хотя BAT сохранял файл в архив один раз.

В новой версии:

- Убрано ограничение на число товаров в ZIP; небольшие порции обработки через REST сохранены.
- В оценке размера учитываются уникальные пути файлов внутри каждого пакета, ZIP и манифест. Состояние расчёта сохраняется между запросами.
- Весь CSV читается до конца. Все пакеты нового плана отмечены по умолчанию.
- Добавлен пересчёт плана без повторной загрузки CSV. Новый план получает отдельный ID, BAT и имена ZIP. Прежние планы и товары сохраняются.
- Увеличен допустимый размер манифеста для крупных пакетов. BAT проверяет фактический размер каждого готового ZIP и не оставляет файл, превышающий введённый лимит.

## Обновление

1. Установите `mik-shop-1.2.1.zip` с заменой текущего MIK Shop. Обновите админку с Ctrl+F5; очистите кеш объединения JS/CSS, если он используется.
2. Откройте MIK Shop → Импорт товаров и выберите ваш прежний импорт.
3. Введите `800` в «Максимум для одного ZIP, МБ» и нажмите «Пересчитать пакеты».
4. После окончания расчёта оставьте отмеченными все пакеты, скачайте новый BAT и сформируйте ZIP заново рядом с папкой `full`.
5. Загружайте новые ZIP из папки нового импорта. Каталог CSV менять не нужно.

800 МБ — верхняя граница, а не требование заполнить каждый ZIP точно до 800 МБ. Сжатие, последний пакет и общий объём файлов каталога могут уменьшать фактический размер. Импортируются изображения и PDF, перечисленные в CSV; весь код и служебные файлы FULL в пакеты не включаются.

Проверки версии 1.2.1 не запускались по указанию заказчика. Установочный архив содержит плагин и инструкции, без каталога и исходной базы.
