# Проверки MIK Shop 1.0.0

Проверки выполнялись после сборки первого установочного ZIP, согласно заданию.

Проверенный код: `c9d19bc587623f1a57b98a940eaa06ee0bd72290`.
GitHub Actions: https://github.com/Jebvo777/arduino-ic/actions/runs/39580915827

- PHP: синтаксис всех 11 файлов; JavaScript: синтаксис обоих файлов.
- HTTP/API: 46 проверок с настоящими WordPress, WooCommerce и MariaDB. Собственные сессии и аккаунты, CSRF, цены групп, корзина, оформление, конкурентное резервирование остатков, отмена, доступ к документам, XLS-вложение письма и пакетный импорт изображения/PDF.
- Chromium: 19 проверок интерфейса: поиск, миниокна, слайдер, оформление, фильтры, список/карточки, кабинет, отсутствие горизонтального переполнения на пяти мобильных страницах и необработанных JS-ошибок. Базовые скриншоты проверены визуально.
- Windows PowerShell 5.1: создание ZIP и запуск настоящего BAT из пути с пробелами.
- XLS BIFF8 независимо прочитан библиотекой xlrd: реквизиты, кириллица и числовые суммы.
- Полный подготовленный каталог: 23 946 товаров, 48 пакетов при лимите 512 МБ, 160 коротких запросов планирования. Приватные данные не отправлялись в GitHub Actions.

Использовались WordPress 7.1.3, WooCommerce 11.2.1, PHP 8.3 и MariaDB 10.11. Тестовые письма перехватывались в тестовом окружении; реальная доставка почты зависит от SMTP хостинга. Т-Банк и СДЭК являются заглушками по заданию. FULL 10 ГБ не скачивался: проверен полный план, фактический импорт медиа — на небольшом тестовом пакете. На боевой сайт плагин не устанавливался. Совместимость с конкретной темой и настройками Elementor проверяется после установки.
