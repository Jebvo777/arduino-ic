# MIK Shop 1.3.0

Обновление категорий, оформления витрины и фирменных изображений. Плагин устанавливается поверх MIK Shop 1.2.4. Каталог, SQL-выгрузка и покупательские данные в установочный ZIP не входят.

## Установка

1. В WordPress откройте «Плагины → Добавить плагин → Загрузить плагин», загрузите `mik-shop-1.3.0.zip` и замените установленную версию MIK Shop.
2. Обновите админку и страницу магазина с Ctrl+F5. Если используется кеш CSS/JS или Elementor, очистите этот кеш.
3. Откройте **MIK Shop → Категории**. Нажмите **«Создать копию и преобразовать категории»**.
4. Сначала создаётся резервная копия категорий, их метаданных, связей с товарами и основных категорий SEO. Только после её завершения запускается преобразование.
5. Задание выполняется порциями на сервере через планировщик WooCommerce Action Scheduler; при его отсутствии используется WP-Cron. Страницу можно закрыть: браузер только показывает прогресс. Для работы требуется действующий серверный планировщик WordPress/WooCommerce.
6. В том же разделе доступны «Пауза», «Продолжить», скачивание JSON и восстановление выбранной копии. При восстановлении сначала создаётся отдельная копия текущего состояния. Восстановление тоже идёт в фоне.

Копия хранится в отдельных таблицах базы WordPress. JSON можно скачать для внешнего хранения; восстановление в интерфейсе использует сохранённую копию из базы. Импорт скачанного JSON отдельным файлом не добавлялся. Во время преобразования не редактируйте массово категории параллельно с заданием.

## Категории

В исходной базе было 684 товарные категории без родителей. Добавлен единый справочник родительских и дочерних разделов. Восемь основных родителей соответствуют блокам на присланном скриншоте:

1. Интегральные микросхемы.
2. Дискретные полупроводники.
3. Диоды и выпрямители.
4. Микроконтроллеры.
5. Пассивные компоненты.
6. Источники питания.
7. Разъёмы и кабели.
8. Защита и термокомпоненты.

Инструменты и комплектующие вынесены в дополнительный родительский раздел. Позиции, тип которых нельзя уверенно определить, направляются в «Прочие компоненты → Требуют уточнения». Полный справочник приведён в [CATEGORIES.md](CATEGORIES.md).

Распределение учитывает старые категории, название, известные семейства маркировок и описание. Это автоматическая классификация по правилам: неоднозначные позиции после преобразования можно уточнить вручную. Она не является электрической проверкой компонента по даташиту.

Старые опустевшие категории архивируются и скрываются из списков, а не удаляются физически. Старые URL перенаправляются на соответствующий раздел. При восстановлении возвращаются названия, родительские связи, метаданные и назначения категорий товарам. Цены, остатки, заказы, аккаунты и файлы товаров этим заданием не меняются.

После преобразования новый импорт использует тот же справочник и не создаёт заново плоские категории из старой выгрузки.

## Категории на главной и в хедере

- **`[mik_category_cards]`** — восемь карточек как в последнем примере: четыре колонки на широком экране, две на планшете, одна на телефоне. Заголовок, ссылки на дочерние разделы, изображение и «Подробнее». Две карточки тёмные.
- **`[mik_header_categories]`** — горизонтальная строка восьми основных категорий и ссылка «Весь каталог».
- **`[mik_header_categories limit="5"]`** — первые пять основных категорий.
- **`[mik_category_cards ids="101,102,103" limit="3" children="3"]`** — явно выбранные категории. Числа замените на реальные ID категорий сайта.
- **`[mik_category_cards parent="101" limit="12"]`** — дочерние категории указанного родителя.
- **`[mik_catalog]`** на `/shop/` без фильтра показывает все родительские категории; на странице категории — её товары и фильтры.

Количество и ID категорий по умолчанию можно менять в «MIK Shop → Контент». На телефоне строка в хедере прокручивается горизонтально.

Изображение категории выбирается так: собственная миниатюра категории → изображение любого опубликованного товара этого раздела → изображение товара дочернего раздела. Если ни у одного товара нет изображения, используется нейтральный значок. Новая фотография не создаётся автоматически. После добавления фото кеш категорий обновится не позднее чем через десять минут.

## Логотип и главный баннер

Встроен синий знак из предоставленного векторного логотипа. Название: **«Купить микросхемы и транзисторы»**. Логотип прозрачный, светлая и тёмная версии; подпись выведена в кривые, поэтому не зависит от наличия шрифта. Рядом с логотипом в хедере показывается предоставленная иллюстрация **Electronic Component**; в узком мобильном хедере она скрывается.

Две фотографии «Фото1» и «Фото2» оптимизированы для сайта и попеременно меняются в **`[mik_slider]`**, сохраняя редактируемые тексты и ссылки баннеров. Используется мягкое размытие и светлая подложка для читаемости. Настройки находятся в «MIK Shop → Контент»: фотографии, включение чередования, тексты и кнопки слайдов.

Важное размещение в Elementor:

- Вместо статического **YourLogo** вставьте виджет «Шорткод» с **`[mik_logo]`**.
- Вместо текста **«Тут категории будут»** вставьте **`[mik_header_categories]`**.
- Блоки категорий в теле главной страницы — **`[mik_category_cards]`**.
- Основной баннер — **`[mik_slider]`**.

Плагин не редактирует чужой шаблон Elementor автоматически. Если в WordPress задан собственный значок сайта, он имеет приоритет над встроенным фавиконом: при необходимости выберите новый `store-favicon.png` в настройках значка сайта.

## Поля, поиск и кнопки

Унифицированы высота, отступы, границы и шрифт текстовых полей и списков в блоках плагина. Устранены крупные шрифты темы в фильтрах и списках категорий. Кнопка поиска закреплена внутри поля справа. Сердечки имеют фиксированные пропорции SVG, кнопки не сжимаются и используют спокойную смену фона при наведении. Счётчик количества сохраняет компактный вид с кнопками «−» и «+».

## Что сохранено из импорта 1.2.4

Указанные при планировании мегабайты остаются **ориентиром** для состава пакетов. BAT создаёт ровно предусмотренные пакеты с исходными именами и составом; фактический ZIP может оказаться больше оценки после переконвертации изображений. Дополнительные ZIP из-за превышения оценки не создаются. Поиск файлов с другим расширением и загрузка архива по ссылке сохранены.

Фоновое преобразование категорий — отдельный механизм. Оно не меняет способ продолжения уже существующего пошагового импорта товаров.
