# MIK Shop 1.1.0 — обновление

## Установка поверх предыдущей версии

В WordPress → Плагины загрузите `mik-shop-1.1.0.zip` и выберите замену установленной версии. Данные товаров, аккаунтов, заказов и импорта сохраняются. Затем очистите кеш Elementor и кеш сайта, чтобы подключился новый CSS/JS.

Информационные страницы используют прежние шорткоды, но теперь имеют полноценную верстку: вводный блок, карточки, шаги, FAQ и кнопку. Их содержимое редактируется в MIK Shop → Контент. Можно добавлять и удалять блоки, менять значки и ссылки. Свой текст сохраняется в дополнительном содержимом. Миграция заменяет только штатные тексты прежней версии.

## Хедер

- `[mik_logo]` — встроенный логотип. Можно указать свой URL в настройках.
- `[mik_search]` — компактный поиск высотой 42 px, максимальной шириной 520 px. Поле занимает доступную ширину внутри этого ограничения.
- `[mik_catalog_button]` — новая компактная кнопка, поиск по категориям и переход к подкатегориям.
- `[mik_account_icon]`, `[mik_wishlist_icon]`, `[mik_cart_icon]` — только значки, без видимых подписей; подписи для доступности и миниокна сохранены.
- `[mik_store_status]` — статус, график и телефон строкой. Телефон скрывается в нерабочее время. На узком экране строка переносится по мере необходимости.

Для хедера Elementor задайте горизонтальный контейнер с выравниванием по центру, интервалом 10–16 px. У виджетов иконок используйте ширину «Встроенная / авто», у поиска — гибкую доступную ширину. Отключите переполнение Hidden у контейнера с миниокнами.

## Мобильное меню

`[mik_mobile_menu]` — поместите в мобильный хедер, например справа от логотипа. Скрытие виджета на десктопе задаётся обычными настройками адаптивности Elementor.

Кнопка открывает нативное полноэкранное модальное меню поверх страницы: логотип, закрытие, AJAX-поиск, кабинет, избранное и корзина с миниокнами, браузер всех категорий и ссылки на все информационные страницы. Подкатегории открываются по уровням; есть поиск и порционное раскрытие. Прокрутка основной страницы блокируется, Escape закрывает меню и возвращает фокус кнопке.

## Футер

`[mik_footer]` — вставьте в Elementor Theme Builder → Footer. Ширина виджета и контейнера — 100%, без внутреннего ограничения ширины. Фон `#242A33`, скругление 5 px уже включены.

Футер содержит логотип, описание, все ваши страницы по группам, контакты, график, персональные страницы и категории. Сотни категорий не образуют длинную простыню: видна подборка из 4–12 основных категорий, поиск по всему дереву и ссылка в каталог. В Контент → Футер можно задать количество и ID выбранных категорий; без ID берутся основные категории. Результаты поиска ограничены по высоте и раскрываются порциями. В API снято прежнее ограничение в 500 категорий.

Логотип для тёмного фона можно указать отдельно. Встроенный вариант футера сочетает цветной знак и светлое название.

## Логотип и значок сайта

`mikrik-logo.svg` — горизонтальный логотип с прозрачностью и обрезанным по изображению viewport. Внутри сохранены сгенерированные пиксели PNG; это не трассированный вектор.

`mikrik-favicon.png` — отдельный квадратный значок с микросхемой. Загрузите его как «Значок сайта» в настройках WordPress. Плагин не меняет глобальный значок сайта автоматически.

## Выпуск

По прямому указанию заказчика проверки версии 1.1.0 не запускались. Автоматический запуск прежнего проверочного workflow при push отключён; его можно вызвать вручную. Отчёт VERIFICATION.md относится к версии 1.0.0. Т-Банк и СДЭК продолжают работать в ранее согласованном режиме заявки.
