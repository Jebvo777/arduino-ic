# MIK Shop 1.2.0

## Что изменилось

### Импорт

Исправлена причина HTTP 422 с сообщением «Недопустимый размер файла или фрагмента» после загрузки первых 1 048 576 байт. `wp_localize_script()` передавал размер фрагмента строкой; JavaScript складывал его со смещением как текст. Следующий фрагмент мог включать весь остаток файла и превышал внутренний предел обработчика.

Размер и смещение теперь обрабатываются как числа; загрузка движется по подтверждённому сервером смещению. Добавлены понятные сообщения о PHP-ошибках, проверка повторного фрагмента, защита от одновременной записи и сохранение прогресса при обрыве. Повторные попытки не выполняются для ошибок валидации 422.

И CSV, и ZIP можно загрузить с компьютера или по прямой общедоступной HTTP(S)-ссылке. Скачивание по ссылке выполняется на сервере с прогрессом, паузой и продолжением при поддержке Range источником. Архивы проходят общую проверку манифеста, принадлежности импорту и медиа. Лимиты: CSV 100 МБ, ZIP 1 ГБ. Архив FULL целиком по-прежнему не нужен.

### Админка

Раздел MIK Shop получил собственную боковую навигацию, обзор с показателями и последними заказами, карточки, таблицы, формы, статусы, модальные окна и пошаговый экран импорта. Оформление использует локальные Inter и Manrope, тёмный `#242A33`, оранжевый `#F85F03`, бирюзовый `#02ADB3` и скругления 5 px. Предусмотрен вариант для узкого экрана.

Внутри раздела «Товары» работает собственный редактор простых товаров: название, SKU, цена, остаток, черновик/публикация, описания, категории с поиском, галерея, PDF, характеристики и Ozon. Загрузка фото, PDF и изображения слайда открывается в собственном окне MIK Shop. Товары остаются товарами WooCommerce.

## Как обновить

1. В WordPress → Плагины → Добавить → Загрузить выберите `mik-shop-1.2.0.zip` и подтвердите замену существующего MIK Shop.
2. Очистите кеш объединения/оптимизации JS и CSS, если он используется. Обновите страницу админки с Ctrl+F5.
3. Откройте MIK Shop → Импорт товаров и повторно выберите ранее выданный `catalog-mik-1.1.0.csv`. Формат файла совместим; переделывать каталог не требуется.
4. Если план пакетов уже был рассчитан, выберите его в предыдущих импортах и продолжайте. BAT и ZIP должны относиться к этому же импорту. Если начали новый импорт, скачайте BAT нового плана.
5. Для URL-загрузки откройте «По ссылке», вставьте прямую ссылку на файл без авторизации и нажмите кнопку скачивания. Подробности — в [инструкции импорта](IMPORT.md).

Шорткоды, страницы, настройки, покупатели и заказы сохраняются при замене файлов плагина. Каталог товаров, SQL и FULL не входят в установочный ZIP.

Автоматические и ручные функциональные проверки версии 1.2.0 не запускались по указанию заказчика. Совместимость с конкретными ограничениями хостинга в этой поставке не проверялась.
