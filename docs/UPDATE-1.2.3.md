# MIK Shop 1.2.3

800 МБ остаётся максимумом одного ZIP. Ошибка Actual files exceed… возникала из-за старых размеров в CSV: BAT находил изображения после конвертации, но не умел дополнительно разделять их, когда они оказывались больше предварительной оценки.

Теперь BAT сначала находит реальные изображения и PDF, измеряет их, вычисляет SHA-256 и делит пакет на самостоятельные ZIP-части. Например, mik-3-0001-part0001-of0003.zip, mik-3-0001-part0002-of0003.zip и mik-3-0001-part0003-of0003.zip. При заполнении части сборка переходит к следующей. Каждый законченный архив измеряется перед выдачей; если несколько файлов не помещаются, часть дополнительно дробится.

Сайт принимает части по одной с компьютера или по прямой ссылке, показывает количество принятых и имя следующей. После получения всех частей пакета запускается обычная обработка товаров небольшими порциями. Изображения одного товара могут лежать в разных частях: привязки сохраняются. Большой общий ZIP на сервере не создаётся; нужны временное место под загруженные части и место под импортированные медиа.

## Обновление и запуск

1. Установите mik-shop-1.2.3.zip с заменой текущего плагина. Откройте админку заново с Ctrl+F5.
2. В MIK Shop → Импорт товаров откройте прежний импорт с лимитом 800 МБ и скачайте **новый BAT**. CSV менять не нужно. Если хотите другой лимит, используйте «Пересчитать пакеты».
3. Запустите новый BAT рядом с папкой full. Сборка появится в новой папке mik-packages-ID/build-дата-время-код. Консоль покажет её полный путь.
4. Загружайте ZIP из **этой новой папки** по списку upload-order.txt. После первой части сайт покажет общее количество и имя следующей части. После последней части пакет готов к обработке; при паузе нажмите «Продолжить».
5. missing-files.txt содержит ненайденные файлы, replaced-files.txt — найденные замены расширений. Старые ZIP и .partial из предыдущих попыток не используйте вместе с новой сборкой.

Размеры в таблице плана предварительные: каталог не содержит актуальных размеров переконвертированных файлов. Фактическое количество ZIP определяет BAT на компьютере. Общий объём материалов может составлять много гигабайт; 800 МБ не ограничивает его сумму. Сжатие и последняя часть могут уменьшать размер отдельных ZIP.

Комплект частей привязан к фактическим файлам. Не смешивайте части разных сборок после изменения FULL. Для обновления уже полностью импортированных пакетов или загрузки другого комплекта создайте новый план через «Пересчитать пакеты». Старые планы и товары сохраняются.

Если один отдельный файл даже после ZIP-сжатия сам превышает выбранный предел, BAT укажет его имя и фактический размер. Такой файл нужно уменьшить либо выбрать больший предел одного ZIP; двоичное разрезание самого изображения на сегменты не используется.

Проверки 1.2.3 не запускались по указанию заказчика. Установочный архив содержит плагин и инструкции, без каталога и исходной базы.
