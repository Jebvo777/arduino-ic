# MIK Shop 1.2.1

Размер в МБ применяется к каждому ZIP. Убран предел 500 товаров на пакет, общие файлы считаются один раз внутри архива; весь каталог распределяется без ограничения суммарного объёма. Добавлена кнопка пересчёта пакетов из уже загруженного CSV.

[Обновление и инструкция](https://github.com/Jebvo777/arduino-ic/blob/main/docs/UPDATE-1.2.1.md). Существующий каталог CSV совместим; для новой разбивки пересчитайте план и скачайте новый BAT.

Проверки не запускались по прямому указанию заказчика. Установочный ZIP не содержит каталог товаров и исходную базу.
