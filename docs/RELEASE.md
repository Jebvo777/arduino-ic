# MIK Shop 1.2.2

BAT находит изображения с тем же именем в той же папке, если расширение изменилось после конвертации: JPG/JPEG, PNG, WebP, GIF, AVIF и другие растровые форматы. ZIP сохраняет действительное имя, манифест связывает его с прежним путём из CSV, а импортёр определяет тип по содержимому. Добавлен отчёт replaced-files.txt.

[Обновление и инструкция](https://github.com/Jebvo777/arduino-ic/blob/main/docs/UPDATE-1.2.2.md). Существующий каталог CSV совместим; скачайте новый BAT и пересоберите ZIP.

Проверки не запускались по прямому указанию заказчика. Установочный ZIP не содержит каталог товаров и исходную базу.
