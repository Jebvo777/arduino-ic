# MIK Shop 1.2.4

Один пакет плана соответствует одному ZIP с исходным именем и составом. BAT сохраняет точное число выбранных архивов, без дополнительного деления и остановки из-за веса. Число в МБ служит ориентиром расчёта по старому CSV; фактический ZIP может быть больше. Ограничения плагина на размер ZIP относительно плана и прежний предел 1 ГБ сняты.

[Обновление и инструкция](https://github.com/Jebvo777/arduino-ic/blob/main/docs/UPDATE-1.2.4.md). Существующие CSV и план совместимы; скачайте новый BAT и загрузите ZIP с именами из плана.

Проверки не запускались по прямому указанию заказчика. Установочный ZIP не содержит каталог товаров и исходную базу.
