# MIK Shop 1.2.3

BAT разбивает найденные файлы на ZIP-части по фактическому размеру, даже если они стали больше после конвертации. Переполнение суммарного размера пакета больше не останавливает сборку. Сайт принимает части, показывает следующий файл и импортирует товары после загрузки полного комплекта без объединения архивов на хостинге.

[Обновление и инструкция](https://github.com/Jebvo777/arduino-ic/blob/main/docs/UPDATE-1.2.3.md). Существующий каталог CSV совместим; скачайте новый BAT и загрузите все ZIP-части из новой папки build-… по списку upload-order.txt.

Проверки не запускались по прямому указанию заказчика. Установочный ZIP не содержит каталог товаров и исходную базу.
