# MIK Shop 1.2.2

Добавлен поиск переконвертированных изображений: если в каталоге записан `folder/photo.jpg`, а в FULL находится `folder/photo.png`, BAT найдёт PNG по той же папке и имени. Каталог CSV редактировать не требуется.

## Как выбирается файл

1. Сначала используется точный путь из каталога.
2. Если его нет, проверяются JPG, JPEG, JPE, PNG, WebP, GIF, AVIF, BMP, DIB, TIF, TIFF, ICO, HEIC и HEIF с тем же именем без расширения в той же папке. Регистр расширения Windows не влияет на поиск.
3. Найденный файл включается в ZIP под действительным именем. Манифест содержит связь со старым путём, поэтому товар получает своё изображение без изменения CSV. Один найденный файл, используемый несколькими путями, добавляется в пакет один раз.
4. Если вариантов несколько, действует указанный порядок расширений. Если ничего нет, путь попадёт в missing-files.txt. Все найденные замены перечисляются в replaced-files.txt рядом с ZIP.

Импортёр поддерживает эти соответствия и дополнительно ищет другие расширения внутри ZIP. Фактический MIME определяет по содержимому, поэтому PNG не сохраняется как JPG только из-за имени в старом каталоге. BMP, TIFF, ICO и HEIC/HEIF преобразуются в PNG при поддержке исходного формата редактором изображений хостинга; иначе журнал показывает понятную причину и имя файла. PDF импортируются как документы.

## Обновление

1. Установите mik-shop-1.2.2.zip с заменой текущего плагина. Откройте админку заново с Ctrl+F5.
2. В импорте откройте ваш существующий план, оставьте нужные пакеты отмеченными и скачайте **новый BAT**.
3. Запустите новый BAT рядом с папкой full и пересоберите ZIP. Прежний BAT не содержит нового поиска.
4. Просмотрите replaced-files.txt и missing-files.txt, затем загрузите новые ZIP. CSV менять не нужно. Если товары пакета уже были полностью импортированы, создайте новый план через «Пересчитать пакеты», скачайте BAT этого плана и соберите его ZIP для обновления товаров.

Лимит размера одного ZIP сохраняется и проверяется по фактическим файлам. Изображения после конвертации могут отличаться по размеру от значений в старом CSV.

Проверки 1.2.2 не запускались по указанию заказчика. Установочный архив содержит плагин и инструкции, без каталога и исходной базы.
