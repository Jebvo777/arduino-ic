## Требования

WordPress 6.5+, PHP 8.0+, WooCommerce, MySQL/MariaDB с InnoDB, расширения PHP ZipArchive и mbstring, HTTPS. Покупательские аккаунты не создаются в WordPress. Администратор использует стандартную учётную запись WordPress с правом manage_woocommerce. Многосайтовая сетевая активация отдельно не поддерживается — активируйте на нужном сайте.

1. Установите WooCommerce. Загрузите `mik-shop-1.2.4.zip` через Плагины → Добавить → Загрузить. При обновлении выберите замену существующего MIK Shop, затем откройте админку заново с Ctrl+F5.
2. Активируйте MIK Shop. Откройте MIK Shop → Настройки, укажите контакты, email заказов, график и реквизиты продавца. До заполнения реквизитов счета не выпускаются.
3. В Обзоре нажмите «Создать недостающие страницы». Существующие страницы сохраняются без изменений. Если они уже существуют, вставьте соответствующий шорткод вручную.
4. Расставьте шорткоды через виджет Shortcode в Elementor. Для соответствующего блока используйте ширину 100% и отключите ограничения ширины внутри Elementor, если они мешают. Фон секции — `#F2F4F7`.
5. Добавьте ссылки на новые страницы в меню. Не вставляйте стандартные WooCommerce Cart/Checkout/My Account в собственные страницы магазина.
6. Настройте отправку писем хостинга/SMTP. Заказы сохраняются независимо от результата wp_mail. В админке можно повторить отправку.

## Шорткоды

| Шорткод | Размещение |
|---|---|
| `[mik_products_carousel]` | Главная — карусель по настройкам админки |
| `[mik_products_carousel title="Новые поступления" source="new" limit="12" columns="4"]` | Подборка новых товаров |
| `[mik_products_carousel title="Для ремонта и разработки" source="all" category="slug" limit="12"]` | Подборка категории, category необязателен |
| `[mik_search]` | Хедер — AJAX-поиск с предрезультатами |
| `[mik_wishlist_icon]` | Хедер — избранное с миниокном |
| `[mik_account_icon]` | Хедер — кабинет с миниокном и входом |
| `[mik_cart_icon]` | Хедер — корзина с миниокном |
| `[mik_catalog_button]` | Хедер — раскрывающийся каталог |
| `[mik_store_status]` | Хедер — телефон, график, открыто/закрыто |
| `[mik_catalog]` | Elementor → Theme Builder → Product Archive |
| `[mik_product]` | Elementor → Theme Builder → Single Product |
| `[mik_product id="123"]` | Обычная страница с конкретным товаром |
| `[mik_cart]` | Страница `/cart-mik/` |
| `[mik_wishlist]` | Страница `/wishlist-mik/` |
| `[mik_account]` | Страница `/lk-mik/` |
| `[mik_wholesale]` | Оптовым покупателям, например `/opt-mik/` |
| `[mik_purchase_info]` | Информация о покупке, `/how-mik/` |
| `[mik_company_info]` | Информация о компании, `/about-mik/` |
| `[mik_contacts]` | Контакты, `/contacts-mik/` |
| `[mik_legal]` | Правовая информация, `/pravo-mik/` |
| `[mik_slider]` | Главная — три редактируемых баннера |

Каталог на `/shop/` показывает категории. В архиве категории — её товары и подкатегории в фильтре, отбор по наличию, цене и параметрам, сортировку, переключатель карточки/список и пагинацию. Результаты поиска открываются на `/shop/?mik_q=...`. Состояние фильтров хранится в URL. В редакторе Elementor задайте preview товара для Single Product; shortcode также принимает id.

Карусель `source="featured"` показывает WooCommerce «Рекомендуемые» (звёздочка в списке товаров). При импорте старые тематические отметки также используются, когда они присутствуют. `source="new"` сортирует по дате, `source="all"` выводит общий каталог. Величина `columns` применяется на широком экране; на телефоне карусель адаптируется.

## Контент и оформление

Вкладка «Контент» редактирует все три слайда, изображения, ссылки, информационные страницы и карусель по умолчанию. Вкладка «Шорткоды» содержит список размещения, названия элементов и дополнительный заголовок/текст каждого блока. В MIK Shop → Товары работает собственный редактор: название, SKU, цена, остаток, публикация, описания, категории, фото, PDF, характеристики и Ozon. Изображения и документы можно загрузить прямо в этом окне. Товары сохраняются в WooCommerce; его обычный редактор также остаётся доступен.

Цвета: фон `#F2F4F7`, карточки белые, заголовки `#242A33`, текст `#454D59`, дополнительный текст `#657080`, акценты `#F85F03` и `#02ADB3`. H1–H2 — Manrope, основной текст — Inter. Шрифты поставляются локально с OFL-лицензиями; внешний запрос Google Fonts для работы плагина не требуется. Можно отключить локальную загрузку, если шрифты уже подключены темой.

Телефон не выводится и ссылка для звонка не создаётся вне выбранных дней/часов. Статус обновляется раз в минуту; часовой пояс по умолчанию — Москва. Это поведение сайта, а не телефонного оператора.

## Аккаунты и коммерческие условия

Физлицо и юрлицо выбираются при регистрации/в профиле. Реквизиты сохраняются отдельно от пользователей WordPress, попадают в заказ и счет. Клиент видит свою ценовую группу и скачивает CSV-прайс. В прайсе есть пустая колонка «Количество»: заполненный CSV до 500 позиций можно вернуть через кабинет для наполнения собственной корзины. Загруженные цены из файла клиента не принимаются — сервер использует текущие цены его группы.

Группы создаются и редактируются во вкладке «Группы и цены». Цены импортируются CSV с колонками `sku;price` либо `Артикул;Цена`. Каждая группа имеет свою валюту. Для рублёвых групп можно явно включить подстановку базовой цены. У USD/EUR автоматической конвертации нет. Товар без групповой цены нельзя оформить до уточнения условий. Базовая цена WooCommerce является публичной; другие группы не добавляются в публичные ответы плагина.

Остаток — свободное для заказа количество. Заказ сразу уменьшает его, отмена возвращает один раз. Статусы управляются администратором. Отменённый заказ нельзя возобновить: потребуется новый. Корзина не резервирует товары до оформления. Для крупных корректировок остатков используйте вкладку «Остатки». После импорта товары обновляются по старому ID или SKU; повторная загрузка старой выгрузки также заменит остаток значением из выгрузки — выполняйте массовое обновление только с актуальными данными.

XLS-заказ формируется в настоящем формате BIFF8, с реквизитами покупателя, и прикладывается к письму менеджеру. Счёт создаётся администратором; после этого доступен в кабинете клиента. Форма счёта открывается для печати и сохранения в PDF средствами браузера. Реквизиты продавца фиксируются на момент выпуска счёта. Это не интеграция с бухгалтерской системой.

Т-Банк и СДЭК по текущему запросу являются заглушками: выбор сохраняется в заказе, деньги не списываются, тарифа доставки API не рассчитывает. Ozon использует прямую ссылку товара, если она известна; иначе открывает поиск по названию. Корзина сайта не переносится на Ozon.

## Кеш и совместимость

Покупательская информация загружается через REST API с `no-store`; цены и сессии не встраиваются в общедоступный HTML шорткода. В CDN/кеширующем плагине исключите `/wp-json/mik/v1/*`, `admin-post.php?action=mik_document`, страницы cart-mik/lk-mik/wishlist-mik. Не кешируйте ответы Set-Cookie. Для корректной работы сервер должен передавать Cookie и заголовок X-MIK-CSRF. WAF не должен блокировать multipart-загрузки авторизованного администратора.

Плагин поддерживает простые товары WooCommerce. Вариативные, подписные и скачиваемые как тип продажи товары в эту версию не входят. PDF здесь — документация к физическим товарам. Обычная корзина WooCommerce и её покупательские аккаунты не используются.

Удаление плагина не удаляет заказы и покупателей. Резервное копирование базы данных и uploads выполняется средствами хостинга. Временная папка PHP должна сохраняться на период пошагового импорта; если хостинг её очищает, загрузите CSV/пакет заново.
