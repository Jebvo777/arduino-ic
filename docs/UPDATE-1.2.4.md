# MIK Shop 1.2.4

Размер в МБ — ориентир для предварительного расчёта по CSV. Если сайт рассчитал четыре пакета при значении 800 МБ, BAT создаст именно четыре ZIP с именами из плана, например mik-3-0001.zip … mik-3-0004.zip. При увеличении изображений после конвертации ZIP может весить 900 МБ или больше.

Дополнительное деление на part-файлы убрано. Состав выбранных пакетов сохраняется: файлы не переносятся между ними из-за изменения фактического размера. Поиск изображения с тем же именем в той же папке с другими расширениями, сопоставление со старым путём CSV, SHA-256, дедупликация общих файлов внутри ZIP и отчёты сохранены.

Сайт принимает целый ZIP без сравнения его размера с ориентиром плана. Сняты прежний предел плагина 1 ГБ и ограничение суммы распакованных файлов относительно планового размера. С компьютера архив передаётся небольшими фрагментами; загрузка по прямой ссылке также сохраняется. Реальные ограничения файловой системы, свободного места и хостинга остаются.

## Обновление

1. Установите mik-shop-1.2.4.zip с заменой текущего плагина. Обновите админку через Ctrl+F5.
2. Откройте прежний импорт, оставьте нужные пакеты отмеченными и скачайте **новый BAT**. Не используйте BAT версии 1.2.3: он создаёт дополнительные части.
3. Запустите BAT рядом с full. В новой папке mik-packages-ID/build-… будет по одному ZIP на каждый выбранный пакет с точным именем из плана.
4. Загружайте их по upload-order.txt. CSV менять или пересчитывать прежний план ради этой версии не требуется.

Если от версии 1.2.3 уже загружены части, но обработка пакета ещё не началась, вместо них можно загрузить целый ZIP этого пакета. Он заменит незавершённый комплект. Уже импортирующийся или завершённый пакет для изменения файлов требует нового плана через «Пересчитать пакеты».

Проверки версии 1.2.4 не запускались по указанию заказчика. Установочный архив содержит плагин и инструкции, без каталога и исходной базы.
