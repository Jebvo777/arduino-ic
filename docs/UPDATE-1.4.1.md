# MIK Shop 1.4.1

Восемь основных категорий используют изображения, предоставленные заказчиком. Для двух дополнительных категорий созданы похожие изображения на прозрачном фоне:

| Категория | Файл внутри плагина |
|---|---|
| Интегральные микросхемы | `assets/img/category-ic.webp` |
| Дискретные полупроводники | `assets/img/category-semiconductors.webp` |
| Диоды и выпрямители | `assets/img/category-diodes.webp` |
| Микроконтроллеры | `assets/img/category-microcontrollers.webp` |
| Пассивные компоненты | `assets/img/category-passive.webp` |
| Источники питания | `assets/img/category-power.webp` |
| Разъёмы и кабели | `assets/img/category-connectors.webp` |
| Защита и термокомпоненты | `assets/img/category-protection.webp` |
| Инструменты и комплектующие | `assets/img/category-accessories.webp` |
| Прочие компоненты | `assets/img/category-other.webp` |

Все десять изображений включены в установочный архив в формате WebP с сохранением прозрачности. Привязки к тестовому домену и фоновым настройкам Elementor больше не требуются. Новые изображения используются в `[mik_category_cards]` и в корневом каталоге `[mik_catalog]`.

## Установка

1. Установить `mik-shop-1.4.1.zip` поверх текущего MIK Shop с заменой файлов.
2. Очистить кеш страницы/CSS/JS, если он используется, и обновить страницу.

Назначение новых изображений выполняется автоматически при первом запуске новой версии. Категории и товары повторно преобразовывать не нужно. Старые ручные URL из поля изображений категорий сохраняются в опции `mik_category_images_previous_141`; для этих десяти категорий включается новый встроенный набор. Последующие ручные изменения сохраняются.

Изменить отдельную картинку можно в **MIK Shop → Контент сайта → Изображения категорий**. Доступны все десять разделов. Пустое поле возвращает встроенную картинку. Шорткоды прежние; полный список — [SHORTCODES.md](SHORTCODES.md).

Исходники восьми изображений перечислены в [CATEGORY-IMAGE-SOURCES.md](CATEGORY-IMAGE-SOURCES.md). Промпты двух новых изображений — в [GENERATED-CATEGORY-ASSETS.md](GENERATED-CATEGORY-ASSETS.md).

В этой поставке не запускались автоматические тесты или проверки на рабочем WordPress, согласно прежнему указанию заказчика.
