# MIK Shop 1.2.3

WordPress/WooCommerce: собственные аккаунты, корзина, избранное, заказы, остатки, счета и пакетный импорт. Т-Банк и СДЭК работают в согласованном режиме заявки.

Установочный архив `mik-shop-1.2.3.zip` выдан отдельно в переписке. [Установка](docs/INSTALL.md) · [Обновление 1.2.3](docs/UPDATE-1.2.3.md) · [Импорт](docs/IMPORT.md)

## Версия 1.2.3

- BAT измеряет фактические файлы после поиска других расширений. Старые размеры CSV используются только для предварительного плана.
- Переполнение пакета создаёт дополнительные ZIP-части вместо остановки по сумме размеров. Каждый законченный ZIP ограничен введённым размером; предусмотрено дальнейшее дробление, если готовый ZIP не помещается.
- Сайт принимает все части пакета, показывает число загруженных и следующую часть. Товары обрабатываются после получения полного комплекта; фото и PDF читаются из нужной части без объединения ZIP.
- Отдельная папка build-… на каждый запуск, upload-order.txt, поиск переконвертированных изображений и SHA-256 сохранены.
- Совместимость с существующим CSV и планами. Для новой сборки скачайте новый BAT.

## Версия 1.2.2

- Если точное изображение отсутствует, BAT ищет то же имя в той же папке с другими расширениями изображения, без учёта регистра Windows.
- JPG/JPEG/JPE, PNG, WebP, GIF, AVIF, BMP/DIB, TIFF/TIF, ICO, HEIC/HEIF. Старые форматы при необходимости преобразуются в PNG средствами хостинга; отсутствие такой поддержки выводится в журнале импорта.
- ZIP хранит действительное имя файла и соответствие пути из CSV. Общий найденный файл попадает в пакет один раз; SHA-256 и предел размера ZIP сохраняются.
- Отчёт о заменах `replaced-files.txt`. Существующий CSV и план совместимы: скачайте новый BAT и пересоберите ZIP.

## Версия 1.2.1

- Ввод размера определяет максимум одного ZIP: весь каталог распределяется на пакеты, общий объём не ограничивается этим числом.
- Убран предел 500 товаров на пакет; общий файл учитывается один раз внутри пакета. Небольшие REST-порции обработки сохранены.
- Добавлен пересчёт всех пакетов из уже загруженного CSV. Создаётся отдельный план с новым BAT; прежние планы и товары сохраняются.

## Версия 1.2.0

- Исправлена ошибка 422 после первого мегабайта: размер фрагмента приводится к числу; продолжение опирается на подтверждённое сервером смещение.
- Загрузка CSV и ZIP с компьютера либо по прямой публичной ссылке, прогресс, пауза и продолжение. ZIP принимается по тому же плану и манифесту.
- Собственная админка в цветах магазина: боковая навигация, обзор, таблицы, формы, статусы, окна, импорт и редактор контента.
- Редактор простых товаров внутри MIK Shop: фото, PDF, категории, описания, характеристики, Ozon, цена и остаток.
- Существующий CSV, страницы, настройки, заказы и покупательские аккаунты сохраняются при замене файлов плагина.

## Версия 1.1.0

- Компактный хедер: иконки без надписей, исправленная геометрия поиска и кнопки каталога, статус работы строкой.
- Информационные страницы с карточками, шагами, FAQ и визуальным редактором блоков в админке.
- Юридическим лицам, оплата, доставка и помощь; «Как купить» использует существующий шорткод покупки.
- Полноширинный тёмный футер `[mik_footer]`, фон #242A33, скругление 5 px, ограниченная подборка категорий и поиск по всему дереву.
- Полноэкранное мобильное меню `[mik_mobile_menu]`: страницы, категории, поиск, корзина, избранное и кабинет с миниокнами.
- Отдельные логотип и favicon; `[mik_logo]` для вставки логотипа в хедер.
- Адреса страниц настроены под пути /about-mik/, /how-mik/, /payment-mik/, /delivery-mik/, /opt-mik/, /yur-mik/, /help-mik/, /pravo-mik/, /contacts-mik/ и существующие страницы магазина. Подкаталог установки сохраняется.

Проверки версий 1.1.0–1.2.3 не запускались по указанию заказчика. Проверочный workflow переведён на ручной запуск. [Архивный отчёт](docs/VERIFICATION.md) относится только к 1.0.0.

Собрать ZIP: `python3 tools/build.py`. Каталог товаров, старая база, заказы, аккаунты и FULL не входят в публичный код и установочный архив.
