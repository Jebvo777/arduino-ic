# MIK Shop

WordPress-плагин магазина электронных компонентов. Товары WooCommerce; собственные покупательские аккаунты, корзина, избранное, заказы, документы и пакетный импорт.

Текущая версия: **1.4.0**.

В версии 1.4.0 обновлены мегаменю, дерево фильтров, три карусели с фотографиями, блок PDF, анимация загрузки, заголовок каталога, слайдер и счётчик количества. Убрана дополнительная иллюстрация рядом с логотипом.

В версии 1.3.0 добавлены родительские и дочерние категории, серверное преобразование с резервными копиями и восстановлением, карточки категорий и горизонтальная строка в хедере. Обновлены логотип, фотографии главного баннера, поля, поиск и кнопки.

## Сборка

```bash
python3 tools/build.py
```

Получится `dist/mik-shop-1.4.0.zip`, который загружается в WordPress поверх прежней версии. Команда сборки не запускает тесты. Документация включается в архив один раз.

SQL-выгрузки, исходные каталоги, покупательские данные и частные аналитические файлы не входят в поставку. Преобразование категорий на рабочем сайте запускается администратором отдельной кнопкой после обновления.
