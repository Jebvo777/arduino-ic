# MIK Shop

Плагин магазина для WordPress и WooCommerce в стиле mikrik.su.

## Этапы

1. Исходные данные, структура и схема импорта.
2. Собственные аккаунты, сессии, корзина, избранное, заказы, остатки и счета.
3. Шорткоды, каталог, карточка товара, кабинет и оформление.
4. Админка и пакетный импорт для shared hosting, генератор Windows BAT.
5. Инструкция и первый установочный ZIP.
6. Проверки после сборки ZIP, исправления и финальная сборка.

До этапа 6 промежуточные тесты не запускаются по указанию заказчика. FULL архив 10 ГБ не скачивается. Исходная база, персональные данные клиентов, приватные реквизиты и подготовленный каталог в публичный репозиторий не публикуются.

## Установка

Инструкция: [docs/INSTALL.md](docs/INSTALL.md). Пакетный импорт: [docs/IMPORT.md](docs/IMPORT.md).

Собрать установочный ZIP: `python3 tools/build.py`. В ZIP попадут папка mik-shop, локальные шрифты, иллюстрации, все файлы PHP/JS/CSS, PowerShell упаковщик и инструкции. Каталог и дополнение с встроенными изображениями выдаются отдельно.

## Режим интеграций

Т-Банк и СДЭК — явные заглушки по текущему заданию. Выбор сохраняется в заявке, оплата не списывается. Ozon — сохранённая ссылка товара либо поиск по имени. Простые товары WooCommerce, собственные покупательские таблицы, без WC_Cart/WC_Checkout/WP_User для клиентов.

## Проверки и готовый архив

[Скачать MIK Shop 1.0.0](https://github.com/Jebvo777/arduino-ic/releases/download/v1.0.0/mik-shop-1.0.0.zip). [Отчёт проверок](docs/VERIFICATION.md): 46 HTTP/API, 19 браузерных, настоящий XLS и Windows BAT. Полный приватный CSV рассчитан на 23 946 товаров. Фактическая установка на боевой сайт не выполнялась.

Сборка релиза запускается после успешных проверок обеих платформ для коммита с `[release]` или вручную через Actions. В публичный релиз входит только плагин с инструкциями.
